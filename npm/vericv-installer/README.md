# VeriCV npm installer

This package installs the VeriCV plugin from the public Cipher Technologies VeriCV marketplace. It is an installer only: it does not read CVs, job descriptions, or candidate data.

```text
npx @ciphertechnologies/vericv codex
npx @ciphertechnologies/vericv claude
```

The installer asks for confirmation, adds or refreshes the marketplace, and installs `vericv`. It includes no accounts, credentials, or remote data service.
