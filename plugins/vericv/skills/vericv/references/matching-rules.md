# Matching rules

## Atomic requirement extraction

Split a job description into independently assessable requirements. Preserve whether a requirement is required, preferred, or merely a responsibility. Avoid promoting vague company language into a hard requirement.

## Classification

| Classification | Use when | Required report content |
|---|---|---|
| Strong Match | Direct CV/profile evidence substantively satisfies the requirement. | Evidence reference and short rationale. |
| Partial Match | The source shows adjacent, limited, incomplete, ambiguous, or differently scoped evidence. | Exact limitation; never silently upgrade it. |
| Not Evidenced | No source evidence supports the requirement. This is not proof the candidate lacks it. | State that it is not documented; suggest a truthful follow-up question where useful. |

## Matching discipline

- Exact terminology is not required for a Strong Match when the same capability is clearly documented.
- Related technologies are usually Partial: PostgreSQL can support relational database experience, but not a claim of MySQL experience.
- A responsibility listed in a job is not evidence that the candidate performed it.
- Treat years/duration as Strong only if the CV's dated experience clearly establishes the threshold for the relevant work. If dates or relevance are ambiguous, use Partial.
- Required education, licences, certifications, and work authorization need direct evidence. Do not infer them from job history.
- A keyword can be recommended only if it is an accurate label for documented experience. Otherwise list it as a gap, not a keyword to insert.

## Gap types

- **Presentation gap:** The evidence exists, but relevant wording, placement, or structure hides it.
- **Evidence gap:** The CV/profile does not document the requirement; a user might be able to clarify it.
- **Qualification gap:** A stated credential, degree, licence, authorization, or hard prerequisite is not documented.

## No scores

Do not calculate a purported ATS score. A requirement count may be used only as an internal organizational aid and must not be presented as a hiring prediction or ATS outcome.
