# Publish VeriCV from GitHub

1. Push this package to the `Lesleykaps/vericv` repository root, including `.codex-plugin/plugin.json` and `skills/vericv/`.
2. Keep the repository, privacy-policy, and terms URLs in `.codex-plugin/plugin.json` in sync with the published files.
3. Run the validation commands in the root README and test the plugin from a clean local installation.
4. Create a release tag such as `v1.0.0`, then use the repository/release as the install source for the intended Codex marketplace or distribution channel.

Do not publish candidate CVs, job descriptions, test fixtures containing personal data, or private API credentials in the repository.
