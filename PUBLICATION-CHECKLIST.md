# VeriCV publication checklist

- [ ] Plugin and skill validation pass.
- [ ] README contains current installation and usage instructions.
- [ ] Version in `.codex-plugin/plugin.json` is updated.
- [ ] Repository, homepage, privacy-policy, and terms URLs are real before adding them to the manifest.
- [ ] Example files contain no real candidate personal information.
- [ ] A clean install can invoke `$vericv analyze`, `$vericv tailor`, and `$vericv batch`.
- [ ] A release tag is created after the final review.
